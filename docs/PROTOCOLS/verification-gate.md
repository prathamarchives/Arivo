# the verification gate

nothing merges without:

- typecheck green (strict, no any)
- eslint green (the dependency law enforced)
- vitest green (the anchor chain, import validation, the portability law)
- for reader changes: the repagination proof — a highlight survives a
  font-size change
- for ui changes: the state check — every screen × every state designed
- for data changes: the round-trip — write → kill index → rebuild → zero loss
