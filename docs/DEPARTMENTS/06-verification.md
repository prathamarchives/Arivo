# dept 06 — integration & verification

owns: the gates. nothing merges without them.

- pnpm check: typecheck (6 projects, strict, no any) + eslint (boundaries)
  + vitest (25 tests: anchor chain, import validation, the portability
  law, export).
- pnpm smoke: the real app boots headless and screenshots itself.
- pnpm dev:web: the renderer + mock api in a browser — the ui dev loop.
- manual passes on the owner's machine: b&w, squint, keyboard,
  reduced-motion, slow machine.

ship checks: green means green. a red gate is not a discussion.
