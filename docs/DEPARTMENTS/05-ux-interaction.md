# dept 05 — ux & interaction

owns: flows, states, keyboard, gestures.

- the spatial model: library = home (browsable), reader = immersion
  (chrome fades, proximity reveals).
- states designed, not retrofitted: empty (first-run = the hello),
  importing, loading, ready, error (honest + recoverable), drifted,
  orphaned.
- keyboard: arrows/space page, ctrl+k palette, ctrl+b bookmark, esc closes
  panels, +/- font size. a mouse is never required.
- the selection moment: select → glass menu settles → color / note /
  bookmark / copy. intellectual, quiet.

ship checks: every state exists. the golden path runs keyboard-only.
