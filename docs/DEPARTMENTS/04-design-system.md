# dept 04 — design system

owns: tokens, materials, components.

- the family: instrument serif (display), inter (ui), literata (reading),
  jetbrains mono (meta). bundled offline via fontsource.
- materials: paper (ground), ink (info), glass (floating chrome only —
  selection menu, palette, menus). three themes: paper / sepia / night.
- the annotation palette (yellow blue green pink gray) is the only hue.
- reading typography: literata, 5 size steps (16-24), lh 1.65, measure
  520-760, justified, oldstyle numerals.
- covers: 2:3 at 160/200/240. motion: 100ms press → 700ms material.
- bans: see the constitution.

ship checks: the squint test passes. it looks like one object.
